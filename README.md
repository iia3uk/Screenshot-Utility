Настольная утилита для Windows: выбираешь область один раз — дальше каждый скрин сохраняется мгновенно, без окон, диалогов и повторного выделения.

Создана как внутренний инструмент для разработки, тестирования UI, документации и подготовки материалов для портфолио.

## Зачем

При разработке и тестировании часто нужно делать десятки одинаковых скриншотов интерфейса. Стандартные средства Windows каждый раз требуют заново выделить область или открыть редактор — это тормозит.

**Screenshot Utility** автоматизирует процесс:

1. Один раз выделяешь область (`F7`)
2. Дальше жмёшь `F8` — PNG уже в папке

## Возможности

| | |
|---|---|
| **Один раз — и готово** | Область выбирается один раз и запоминается |
| **Глобальные хоткеи** | Работают поверх любого окна |
| **PNG без потерь** | Скриншоты сохраняются сразу в PNG |
| **Без лишних окон** | При захвате ничего не всплывает |
| **Конфиг в JSON** | Координаты переживают перезапуск |
| **По времени** | Файлы именуются с датой и временем |

## Как работает

| Клавиша | Действие |
|---------|----------|
| `F7` | Выбрать область экрана |
| `F8` | Сохранить скриншот выбранной области |
| `Esc` | Отменить выбор области |

Скриншоты складываются в папку `screenshots/` рядом со скриптом.  
Координаты области — в `screenshot_config.json`.

## Быстрый старт

### Требования

- Windows
- Python 3.10+

### Установка

```bash
git clone https://github.com/iia3uk/Screenshot-Utility.git
cd Screenshot-Utility
pip install -r requirements.txt
```

### Запуск

```bash
python region_screenshotter.py
```

или двойной клик по `start.bat`.

В консоли появится подсказка:

```
============================================================
Скриншотер запущен
F7  -> выбрать область
F8  -> сделать скрин
============================================================
```

## Структура
